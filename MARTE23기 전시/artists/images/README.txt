이미지 업로드 가이드
==================

이 폴더에 각 작가의 이미지를 업로드해주세요.

필요한 이미지:
1. work-placeholder.jpg - 작품 이미지 (가로형 권장, 최소 1200px 이상)
2. artist-placeholder.jpg - 작가 사진 (정사각형 권장, 최소 400x400px)

각 작가별로 구분하려면:
- work-kim-yeonho.jpg, artist-kim-yeonho.jpg 형식으로 저장하고
- HTML 파일에서 이미지 경로를 수정해주세요

예시:
<img src="images/work-kim-yeonho.jpg" alt="작품 이미지" class="work-image">
<img src="images/artist-kim-yeonho.jpg" alt="작가 사진" class="artist-photo">
