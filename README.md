# 보는소리, 듣는영상 | SEEING SOUND LISTENING IMAGE 2026

한국멀티미디어음악학회 SIMM 전시 사이트입니다. GitHub Pages로 호스팅되는 정적 사이트이며,
메인 페이지 배경 영상은 로컬 파일을 사용합니다.

## 로컬 실행

`index.html`을 브라우저에서 열면 됩니다.

## 배경 영상 교체

메인 페이지 배경 영상은 로컬 파일을 사용합니다.

- 파일: `DYSTOPIA_VANISHED_SOUNDS.mp4`
- 교체 방법: 동일한 파일명으로 덮어쓰거나 `index.html`의 `<source>` 경로를 변경하세요.

## 저작권 및 사용 범위 (콘텐츠)

- 전시 작품(영상/이미지/오디오 등) 및 작가별 콘텐츠의 저작권은 각 작가에게 있습니다.
- 로고(`SIMM_Logo.png`) 및 전시 관련 명칭은 한국멀티미디어음악학회 SIMM에 귀속됩니다.

  별도 허락 없이 재배포/상업적 이용을 금합니다.
