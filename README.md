# 보는소리, 듣는영상 | SEEING SOUND LISTENING IMAGE 2026

한국멀티미디어음악학회 SIMM 전시 사이트입니다. GitHub Pages로 호스팅되는 정적 사이트이며,
메인 페이지 배경 영상은 로컬 파일을 사용합니다.

This is the exhibition website of the Society of International Music and Media (SIMM).
It is a static site hosted on GitHub Pages and uses a local video file as the main
page background.

## 로컬 실행 / Local Run

`index.html`을 브라우저에서 열면 됩니다.

Open `index.html` in your browser.

## 배경 영상 교체 / Replace Background Video

메인 페이지 배경 영상은 로컬 파일을 사용합니다.

The main page background uses a local video file.

- 파일 / File: `DYSTOPIA_VANISHED_SOUNDS.mp4`
- 교체 방법 / Replace: 동일한 파일명으로 덮어쓰거나 `index.html`의 `<source>` 경로를 변경하세요.
  Overwrite with the same filename or change the `<source>` path in `index.html`.
