# SEEING SOUND LISTENING IMAGE 2026

This is the exhibition website of the Society of International Music and Media (SIMM).
It is a static site hosted on GitHub Pages and uses a local video file as the main
page background.

## Local Run

Open `index.html` in your browser.

## Replace Background Video

The main page background uses a local video file.

- File: `DYSTOPIA_VANISHED_SOUNDS.mp4`
- Replace: Overwrite with the same filename or change the `<source>` path in `index.html`.
